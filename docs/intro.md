# Introduction

Welcome to **3D Print Shop Software** — the ERP and workflow automation platform purpose-built for print farm operators.

## What is 3D Print Shop Software?

3D Print Shop Software streamlines the entire lifecycle of 3D print operations:

- **Job Costing**: Track material costs, machine time, and labor with precision
- **Pricing Calculations**: Auto-generate competitive quotes based on real operational metrics
- **Inventory Management**: Monitor filament stock, resin, and material usage in real time
- **Maintenance Tracking**: Schedule and log equipment maintenance to maximize uptime
- **Risk Flagging**: Identify problematic customers and high-risk orders early
- **BOM Auto-Generation**: Automatically create bills of materials from design files

## Who is it for?

Whether you're running a single Bambu Lab printer or a distributed farm across multiple facilities, this software scales with you.
