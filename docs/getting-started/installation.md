# Installation

Get 3D Print Shop Software up and running on your system.

## System Requirements

- Excel 2016 or later (or compatible spreadsheet application)
- Windows 7+ or macOS 10.12+
- 100 MB free disk space
- Internet connection (for initial setup and updates)

## Download & Setup

1. **Purchase and Download**
   - Download the latest release from [Gumroad](https://gumroad.com)
   - You'll receive a `.xlsx` file

2. **Enable Macros**
   - Open the file in Excel
   - Click **Enable Editing** at the top
   - Select **Enable Content** when prompted about macros

3. **Initial Configuration**
   - Complete the setup wizard on the "Configuration" sheet
   - Enter your facility details, machine specs, and material costs
   - Save the file to your preferred location

4. **Create a Backup**
   - Make a backup copy immediately
   - Store it in a safe location (cloud storage recommended)

## Updating

New versions are released periodically. To update:

1. Download the latest version from your Gumroad account
2. Create a backup of your current data
3. Export your historical data (if needed)
4. Replace the old file with the new version
5. Re-enter your configuration

## Troubleshooting

**Macros not working?**
- Ensure macros are enabled in your Excel security settings
- Try opening in "Edit Mode"

**Data not displaying?**
- Check that all sheets are visible (not hidden)
- Refresh calculations with Ctrl+Shift+F9

**Performance issues?**
- Consider splitting large datasets into separate workbooks
- Archive completed projects regularly
